# MproWave API Documentation

## Base URL

```
http://localhost:8000/api
```

## Authentication

All protected endpoints require Bearer token authentication.

Include the token in the Authorization header:

```
Authorization: Bearer {your_token}
```

---

## Authentication Endpoints

### Register User

```http
POST /auth/register
```

**Request Body:**
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "password123",
  "password_confirmation": "password123"
}
```

**Response:**
```json
{
  "user": {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
  },
  "token": "1|abc123...",
  "token_type": "Bearer"
}
```

### Login

```http
POST /auth/login
```

**Request Body:**
```json
{
  "email": "john@example.com",
  "password": "password123"
}
```

**Response:** Same as register

### Logout

```http
POST /auth/logout
```

**Headers:** Requires authentication

### Get Current User

```http
GET /auth/user
```

**Headers:** Requires authentication

  "muted": false,
  "solo": true

```http
DELETE /tracks/{id}
```

```http
POST /tracks/{id}/upload
```

**Request:** multipart/form-data

## AI Assistant Endpoints

Text-based suggestions (MIDI patterns, harmony, drums) are generated by
DeepSeek. Endpoints that take an `audio_file` first run it through the local
audio analysis microservice (Demucs/basic-pitch) to extract notes, tempo,
and key, then pass those extracted features to DeepSeek as text — DeepSeek's
API does not accept audio input directly.

### Generate MIDI Pattern

```http
POST /ai/generate-midi
```

**Request Body:**
```json
{
  "prompt": "Generate a happy melody",
  "duration": 8,
  "key": "C",
  "scale": "major"
}
```

**Response:**
```json
{
  "midi_data": [
    {
      "note": "C4",
      "start": 0,
      "duration": 0.5,
      "velocity": 80
    }
  ],
  "format": "midi"
}
```

### Suggest Harmony

```http
POST /ai/suggest-harmony
```

**Request:** multipart/form-data
- `audio_file`: Audio file to analyze
- `context`: Optional context string

**Response:**
```json
{
  "suggestions": "...",
  "chords": ["Cmaj", "Fmaj", "G7"],
  "scale": "C major",
  "detected_tempo_bpm": 118.2,
  "detected_key": "C"
}
```

### Generate Drums

```http
POST /ai/generate-drums
```

**Request Body:**
```json
{
  "style": "rock",
  "bpm": 120,
  "bars": 4
}
```

### Analyze Audio

```http
POST /ai/analyze-audio
```

**Request:** multipart/form-data
- `audio_file`: Audio file to analyze

**Response:**
```json
{
  "analysis": "...",
  "bpm": 120,
  "key": "C",
  "genre": "pop",
  "notes": [{"start": 0.0, "end": 0.5, "pitch": 60, "amplitude": 0.8}],
  "duration_sec": 32.4
}
```

## Stem Separation Endpoints

Stems are separated by a local Demucs microservice
(see [audio-service](../audio-service/README.md)). The request currently
blocks until separation finishes (no background queue is set up), so expect
it to take anywhere from several seconds to a few minutes depending on
track length and hardware. `job_id`, `status`, and `download` are still
returned/available for a consistent polling-style contract.

### Separate Stems

```http
POST /stems/separate
```

**Request:** multipart/form-data
- `audio_file`: Audio file to separate
- `stems[]`: Array of stem types (vocals, drums, bass, other)

**Response:**
```json
{
  "job_id": "uuid",
  "status": "completed",
  "message": "Stem separation complete."
}
```

### Check Separation Status

```http
GET /stems/{job_id}/status
```

**Response:**
```json
{
  "job_id": "uuid",
  "status": "completed",
  "created_at": "2024-01-01T00:00:00Z"
}
```

### Download Stems

```http
GET /stems/{job_id}/download
```

**Response:**
```json
{
  "stems": [...],
  "download_urls": {
    "vocals.wav": "https://...",
    "drums.wav": "https://..."
  }
}
```

## Error Responses

All endpoints return standard error responses:

**400 Bad Request:**
```json
{
  "message": "Validation error",
  "errors": {
    "field": ["Error message"]
  }
}
```

**401 Unauthorized:**
```json
{
  "message": "Unauthenticated."
}
```

**404 Not Found:**
```json
{
  "message": "Resource not found"
}
```

**500 Server Error:**
```json
{
  "message": "Server error"
}
```
